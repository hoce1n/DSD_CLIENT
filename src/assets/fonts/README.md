# 📝 راهنمای آپلود و استفاده از فونت‌های سفارشی

## 📁 ساختار پوشه فونت‌ها

```
src/assets/fonts/
├── headers/          # فونت‌های تیتر و سرفصل‌ها
│   ├── font-name.woff2
│   ├── font-name.woff
│   └── font-name.ttf
├── body/            # فونت‌های متن اصلی
│   ├── font-name.woff2
│   ├── font-name.woff
│   └── font-name.ttf
└── README.md        # این فایل
```

## 🎯 مراحل آپلود فونت‌ها

### 1️⃣ آپلود فونت تیترها
- فونت‌های تیتر و سرفصل‌ها را در پوشه `headers/` قرار دهید
- نام‌گذاری: مثلاً `YekanBakh-Bold.woff2`

### 2️⃣ آپلود فونت متن اصلی  
- فونت‌های متن اصلی را در پوشه `body/` قرار دهید
- نام‌گذاری: مثلاً `Vazirmatn-Regular.woff2`

## 📋 فرمت‌های پیشنهادی (اولویت‌بندی شده)
1. **.woff2** - بهترین فرمت (حجم کم، کیفیت بالا)
2. **.woff** - پشتیبانی backup برای مرورگرهای قدیمی
3. **.ttf** - فقط در صورت ضرورت

## ✅ پس از آپلود فونت‌ها
بعد از آپلود فونت‌ها، به من اطلاع دهید تا:
- فایل CSS font-face بسازم
- کلاس‌های Tailwind سفارشی تعریف کنم  
- فونت‌ها را در پروژه فعال کنم

## 🎨 پیشنهادات فونت فارسی
### برای تیترها:
- **یکان باخ (Yekan Bakh)** - مدرن و خوانا
- **وزیر بلک (Vazir Black)** - پررنگ و تأثیرگذار
- **شبنم (Shabnam)** - زیبا و حرفه‌ای

### برای متن اصلی:
- **وزیر متن (Vazirmatn)** - استاندارد طلایی
- **ایران‌یکان (IRANYekan)** - محبوب و خوانا  
- **دانا (Dana)** - مدرن و سبک
